# Synthetic typography fixture

These files illustrate the shared manuscript style using artificial values.
They are not patient findings. The example uses the bundled DejaVu Sans font,
16-point titles/axis titles, 14-point labels, and the configured primary/recurrent
colors. PNG/JPEG are 4320 × 2880 pixels (7.2 × 4.8 inches at 600 pixels/inch).
PDF and the standard SVG use outlined fonts for portability; editable.svg retains
text. Regenerate the fixture with `rna_plot_smoke_test()` from the README.
